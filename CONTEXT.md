# FocusQuote

The shared language for FocusQuote — a Chrome extension and backend for capturing web quotes and running goal-oriented focus sessions with AI assistance. This glossary is the source of truth for what domain terms mean; prefer these words over the alternatives listed under _Avoid_.

## Language

**Session**:
A timed period of focused work toward a goal, during which the extension tracks the pages visited and actions taken.
_Avoid_: Pomodoro, timer

**History**:
The view of past focus sessions surfaced for later review (today, the sessions older than the last week).
_Avoid_: Archive, Storage

**Topic**:
A research subject that groups focus sessions sharing a theme and owns a Vault. The AI suggests its name, but a Topic has a stable identity independent of that name.
_Avoid_: Category, folder

**Vault**:
The information a user keeps under a Topic — text notes, saved URLs, and screenshots — collected for later recall.
_Avoid_: Storage, archive

**Vault item**:
A single curated piece in a Topic's Vault: a note, a saved URL, or a screenshot. Curated by the user, distinct from the pages a session tracks automatically.
_Avoid_: Attachment, resource

**Tracked visit**:
A page the extension recorded automatically during a session for distraction analysis (`SessionUrl`). Telemetry, not curated knowledge — promoting one into the Vault turns it into a Vault item.
_Avoid_: Visit, history entry, session URL

**Tag**:
A subject a Quote is filed under. Tags form a graph: a Tag may have several parent Tags, and a Quote may carry several Tags. The AI assigns and maintains them; a Tag a user creates or edits is pinned and the AI leaves it alone. A Tag has a stable identity independent of its name.
_Avoid_: Folder, category, label, node

**Consolidation**:
The user-triggered pass ("Tidy now") in which the AI restructures the Tag graph — merging duplicates, renaming, re-parenting, splitting — and re-files only the Quotes those changes touch. Distinct from the lightweight tagging that happens automatically when a Quote is saved, which only attaches a Quote and creates Tags.
_Avoid_: Cleanup, reorg, sync

**Conversation**:
A persistent Quote+AI chat scoped to a single article (page URL). Highlighted passages are added as context to individual turns; they don't start separate chats. Persists locally and syncs when signed in.
_Avoid_: Thread, chat session

**Goal**:
The forward-looking intent a user sets for a Session — what they mean to accomplish. User-authored.
_Avoid_: Title, task

**Title**:
A short retrospective label for a Session, generated by AI from its Topic and tracked visits. Shown when no Goal was set; never overwrites a Goal.
_Avoid_: Goal, name

**Job Application Session**:
A Session focused on applying to jobs, identified when the Goal contains job-related keywords or by explicit selection. Enables answer generation for application questions.
_Avoid_: Interview mode, application mode

**Application Profile**:
The CV (plain text) and Answer Bank stored locally in the extension. Required for generating personalized answers during Job Application Sessions.
_Avoid_: Resume, user profile, bio

**Answer Bank**:
The collection of pre-answered questions with the user's responses, seeded with editable defaults. Used as context for generating answers to Job Questions.
_Avoid_: Template library, answer cache, question set

**Answer Template**:
A single question/answer pair in the Answer Bank. Can be from the default seed list, user-edited, or user-added.
_Avoid_: Saved answer, answer preset

**Job Question**:
Text selected during a Job Application Session that needs an AI-generated answer. Classified as either Reusable or Contextual.
_Avoid_: Interview question, application prompt

**Reusable question**:
A Job Question whose answer applies across all companies (e.g., "What are your strengths?"). The Generated Answer can be saved as an Answer Template for reuse.
_Avoid_: Generic question, universal question

**Contextual question**:
A Job Question specific to a company or role (e.g., "Why do you want to work at Acme Corp?"). Generated fresh each time using Company Context, not saved in the Answer Bank.
_Avoid_: Company-specific question, dynamic question

**Generated Answer**:
The AI-produced response to a Job Question, created using the Application Profile and optionally Company Context. Editable and regenerable before copying.
_Avoid_: AI response, generated response

**Company Context**:
Information about a specific company (mission, values, description) researched by scraping the job page and web search. Used for Contextual questions, cached locally per company.
_Avoid_: Company profile, company research, company data
